# 参考资料副本

本目录中的文件均复制自项目根目录的 `原始数据`，仅用于协议分析、开发参考和测试样例提取。

## 强制规则

- 不执行 `legacy-php` 中的旧脚本。
- 不将本目录部署为 Web 公开目录。
- 不把这些副本配置为生产日志或上传目录。
- 需要修改脚本时，在正式应用目录重新实现；需要提取测试样例时，复制并脱敏到 `tests/fixtures`。
- 原始目录始终只读，历史日志也必须先复制到其他工作目录后处理。

## 内容

- `legacy-php/`：四个原始 PHP 回调脚本的未修改副本。
- `protocol/`：Gateway 2.4 中英文文档、EIMS 3.5 中文文档和 ETMS 文档。
- `SHA256SUMS.txt`：本次复制件的 SHA-256 清单。

首版协议实现以 Gateway 2.4 为主。EIMS 和 ETMS 是不同接口资料，不应混用其 URL、字段或状态码。
